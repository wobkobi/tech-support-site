# Left-chest embroidery artwork

Artwork for the embroidered polos and fleeces. These are artwork files, not stitch files: an
embroiderer digitises them to DST/PES. `embroidery-spec.txt` is the brief that went out with them
(garments, thread, stitch, backing), kept as sent.

The spec names each option by code. The code is dropped from the filenames here, so this table maps
them back.

| Code | File                                                                 | Size (mm) |
| ---- | -------------------------------------------------------------------- | --------- |
| A2   | `chip-beside-name-103x46mm` - **the design in use**                  | 103 x 46  |
| A3   | `other-designs/chip-beside-to-the-point-tech-support-below-103x60mm` | 103 x 60  |
| A4   | `other-designs/chip-beside-name-tech-support-below-103x60mm`         | 103 x 60  |
| B1   | `other-designs/name-inside-chip-86x86mm`                             | 86 x 86   |
| B2   | `other-designs/name-inside-chip-tech-support-below-86x100mm`         | 86 x 100  |
| B3   | `other-designs/to-the-point-inside-chip-tech-support-below-86x100mm` | 86 x 100  |

Each design is one SVG, drawn at finished size in millimetres, with layers named `thread-white` then
`thread-orange` in stitch order. The spec also mentions PDFs, previews on navy and 600dpi PNGs;
those are not kept here.

A1 and C2 from the spec were not kept.
